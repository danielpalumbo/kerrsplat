I would like to build a a differentiable inference code for Gaussian splatting of plasma into the Kerr spacetime. This would ultimately produce 4-d descriptions of the plasma near the black hole as a fit to spectro-polarimetric movies of the near-horizon region. The inspiration comes from a recent string of projects applying neural radiance fields to a much easier version of this problem; the most recent such paper is Feng_2026.pdf, in this directory. There are two possible ray tracing codes that might be worth using for this purpose. The first is Krang.jl, which is described online on Github but is also installed locally in /home/daniel/local_scripts/Krang.jl. The second is Jipole, described in various papers and probably also a github repo you can find on the web led by Pedro Motta. Please carefully review the two codes and evaluate which could more easily be connected to a Gaussian splatting code. Then, make a plan for a new Julia-based project with a dependency on one of these Julia-based codes that would place time-dependent plasma into the Kerr spacetime using Gaussian splatting, fitting to an observer-frequency-dependent movie of the Stokes I, Q, U, and V parameters. For this project, thoroughness and accuracy matters orders of magnitude more than speed, so please take your time. Write your conclusions about the best path forward to a markdown file in this directory.
